# Ant-Lotm · Анкетарий

Русскоязычный анкетарий персонажей по миру «Повелителя тайн» (Lord of the Mysteries).

## Открыть на ПК без установки

1. [Скачайте готовую версию Ant-Lotm-PC.zip](https://github.com/f4381809-ui/Ant-Lotm/raw/refs/heads/main/downloads/Ant-Lotm-PC.zip).
2. Распакуйте архив в папку на компьютере.
3. Откройте `Ant-Lotm.html` двойным щелчком в Chrome, Edge или Firefox.

Приложение работает без интернета, Node.js и сервера. При обновлении HTML-файла, его перемещении или смене браузера сначала скачайте JSON-архив персонажей внутри приложения, затем импортируйте его в новой версии. Хранение данных для локальных HTML-файлов зависит от браузера и расположения файла.

## Публикация сайта на GitHub Pages

Готовая версия находится в `docs/`. В настройках репозитория откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main**, папку **/docs** и нажмите **Save**. После успешной публикации GitHub покажет ссылку на сайт.

Ожидаемый адрес: `https://f4381809-ui.github.io/Ant-Lotm/`. Наличие файлов в Git само по себе не включает Pages; доступность публикации зависит от настроек репозитория и тарифа GitHub.

## Возможности

- Несколько персонажей: имя, прозвище, путь, последовательность, зелье, биография и принципы отыгрыша.
- Портрет персонажа: загрузка JPG, PNG и WebP до 12 МБ, предпросмотр, замена и удаление. Изображение автоматически уменьшается и входит в резервную копию; старые анкеты без портрета поддерживаются.
- Дневник с событиями, заметками и изменениями усвоения зелья от 0 до 100%.
- Автоматический расчёт по настраиваемым правилам: базовые баллы за тип события и бонусы за отмеченные принципы, новое понимание роли и сложную ситуацию. Перед сохранением видны прибавка и её объяснение; расчёт сохраняется в записи.
- Правила для каждого персонажа: баллы до 100%, веса событий и бонусов, предел за сцену, автоматический или ручной режим по умолчанию. Новые правила не меняют уже начисленное усвоение.
- Запись прямо в анкете: большое поле, авторасчёт или ручные прибавки 0 / +1 / +5 / +10%, своё значение и отправка через Ctrl+Enter. Если заголовок не указан, используется первая строка текста.
- Черновики для каждого персонажа сохраняются на устройстве и восстанавливаются после перезагрузки. Они не входят в JSON-экспорт, пока запись не сохранена.
- Поиск по дневнику и исправление текста записей без изменения даты и ранее начисленного усвоения.
- Настройка оформления: светлая, ночная и системная темы, готовые акценты и свой цвет, три размера текста, книжный шрифт записей, плотность, ширина страницы и высота редактора.
- Личное название архива, отключение отдельных карточек и режим письма без боковых панелей. Кнопка возврата панелей всегда доступна сверху. Анимацию можно отключить.
- Кубики d4, d6, d8, d10, d12, d20, d100 и свои от 2 до 1000 граней: от 1 до 20 кубиков, модификатор от −999 до +999, сумма, отдельные значения и история последних 30 бросков.
- Вставка броска в черновик дневника без потери набранного текста. Пустой редактор получает заметку с нулевой прибавкой к усвоению; существующая прибавка не меняется. Бросок сам по себе не создаёт запись и не меняет персонажа.
- При полном усвоении — ручное продвижение к следующей последовательности. Прогресс нового зелья начинается с нуля, история сохраняется.
- Локальное сохранение, экспорт и импорт JSON-архива. Совпадающие анкеты заменяются только после подтверждения.
- Адаптивный интерфейс для компьютера и телефона.

Кнопки **«Оформление»** и **«Кубики»** находятся в верхней панели и доступны на любой странице. Оформление применяется сразу и сохраняется на устройстве. Сброс оформления не удаляет анкеты, портреты, дневник или броски.

JSON-архив версии 2 включает персонажей, портреты, настройки и общую историю бросков. Старые архивы версии 1 и массивы анкет по-прежнему поддерживаются и не заменяют оформление или кубики. Настройки из нового архива восстанавливаются после подтверждения; некорректные данные отклоняются до изменения существующих анкет.

## Как считается автоматическое усвоение

Напишите описание события и отметьте результаты сцены. По умолчанию отыгрыш даёт 2 балла, исследование и ритуал — по 1; применение одного или нескольких принципов добавляет 2 балла, новое понимание роли — 3, сложная ситуация — 1. Предел одной сцены — 8 баллов, а 100 баллов соответствуют 100% усвоения. Это редактируемая игровая формула, не канон и не ИИ-анализ текста.

В каждой новой записи можно выбрать **«Автоматически»** или **«Вручную»**. Кнопка **«Правила»** в редакторе и **«Настроить»** под зельем открывают параметры текущего персонажа. Старые проценты становятся исходным прогрессом; мелкие доли накапливаются без потери при округлении. До полного достижения порога приложение не покажет 100%.

Заметки, пустые описания и отдельные результаты кубиков дают 0 автоматических баллов. Совпадающее описание уже зачтённой сцены не получает повторную прибавку; для самостоятельного повторного события есть отметка «Это другая сцена». Проверка повторов относится только к текущему зелью. После продвижения начинается новый счёт, а старые записи и их расчёты остаются.

Исправление текста записи не пересчитывает прошлое усвоение: первоначальные признаки сцены, её описание и параметры сохраняются для аудита. Старые черновики с ручной прибавкой восстанавливаются в ручном режиме, чтобы не изменить незавершённую запись.

Анкеты хранятся только в `localStorage` текущего браузера и источника (адрес + порт). Сервера, аккаунтов и синхронизации пока нет. Перед очисткой данных браузера скачайте архив. Названия зелий, принципы отыгрыша и прибавку к усвоению определяют игрок и ведущий; приложение не проверяет канонические условия продвижения.

## Разработка

Требуется Node.js 22.18+ (проверено на Node.js 24.19.0) и npm.

```sh
npm ci
npm run dev
```

Vite использует порт 5173 по умолчанию. React, TypeScript; все ресурсы локальные, внешних API и ключей не требуется.

## Проверки

```sh
npm test
npm run build
```

`npm test` проверяет усвоение, автоматические начисления и их пределы, повторные сцены, точное накопление дробей, смену правил и зелий, исправление текста, совместимость старых архивов, портреты, настройки, контраст кнопок, диапазоны и суммы бросков и проверку всего архива перед импортом. `npm run build` запускает проверку типов и создаёт production-сборку в `dist/`.

Для локальной проверки сборки: `npm run preview`.

## Обновить готовую версию для ПК и Pages

```sh
npm run build:pc
```

Команда создаёт автономный `docs/index.html` со встроенными JavaScript и CSS, а затем архив `downloads/Ant-Lotm-PC.zip`. Обновлённые файлы `docs/` и `downloads/` нужно отправлять в Git вместе с исходным кодом. `docs/` — каталог сборки, его содержимое перезаписывается этой командой.
